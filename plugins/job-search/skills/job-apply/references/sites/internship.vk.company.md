# internship.vk.company — анкета стажировки VK (одна форма на все вакансии)

Форма длинная (~20 полей), все выпадашки — Ant Design.
- Списки (Пол, Город, Гражданство, Учебное заведение, Факультет, Степень, Курс, Направление, «Откуда знаешь»,
  английский) — только `antselect <ref> <текст>`; `select` падает («Element is not a <select>»).
- После выбора snap показывает пункт в `value="…"` — сверяй по нему, скриншоты для проверки не нужны.
- Город — поиск с автодополнением: на «Москва» есть «Москва», «Москва (деревня)», «Новая Москва».
  `antselect` берёт точный пункт; `pick` не использовать (берёт последнее совпадение).
- Гражданство: в списке только «Россия | Другое». При «Другое» появляется обязательное текстовое поле
  «Укажите гражданство» (`custom_citizenship`) — в плане должно быть отдельным полем с гражданством из профиля.
- Учебное заведение: ищется по короткому имени («МИРЭА» → «РТУ МИРЭА»); в плане — полное имя пункта «РТУ МИРЭА».
- Факультет: длинные названия, поиск по началу («Институт кибербезопасности» → полный пункт).
- Курс: пункты вида «3 курс» — в плане писать так же, не «3».
- Направление обучения: ФИИТ в списке нет — выбирать «Другое».
- «Откуда ты знаешь о проекте?»: пункты длинные («Группа Changellenge в соц.сетях» и т.п.) — в плане писать
  пункт целиком, как в списке.
- Год поступления/окончания — обычные текстовые поля, `fill`.
- Резюме — `upload` в input type=file («Добавить резюме»); сопроводительное — textarea.
